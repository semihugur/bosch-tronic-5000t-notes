# Bosch Tronic 5000 T (TR5501iTR 100 DEBP WiFi) — owner field notes

Notes from installing and running the Bosch Tronic 5000 T electric water heater with the HomeCom Easy app. They cover problems that are not documented online.

**Read the page:** see `index.html`, published with GitHub Pages.

## Covered

- Schedule / Programme mode blinks 5 times and returns to Manual: the unit has no stored schedule (manual §4.5.4, §4.12)
- Switching off or a power cut erases the schedule
- Thermal disinfection: 65°C for up to 1 h after a power interruption, with its own app screen
- Why it heats before the schedule window
- Pairing with HomeCom Easy: 2.4 GHz only, credentials sticker, firmware "Updating…"
- Safety valve dripping: ~1.5–2 L per heat-up is normal
- Wrong leads to skip
